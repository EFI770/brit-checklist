# הכנות לברית - צ'קליסט אינטראקטיבי

אפליקציית ווב (PWA) לצ'קליסט הכנות לברית מילה בסגנון חב"ד.

## כתובת האתר
לאחר הפעלת GitHub Pages:
**https://efi770.github.io/brit-checklist/**

## איך להפעיל את GitHub Pages (כדי שהאתר יהיה פומבי עם כתובת)
1. היכנס ל-Repository: https://github.com/EFI770/brit-checklist
2. לחץ על **Settings**
3. בתפריט השמאלי בחר **Pages**
4. תחת **Source** בחר **Deploy from a branch**
5. בחר branch: **main** ו-folder: **/ (root)**
6. לחץ Save

תוך דקה-שתיים האתר יהיה זמין בכתובת למעלה.

## תכונות
- צ'קליסט מפורט לשלבים לפני, אחרונות וביום הברית
- שמירה אוטומטית ב-localStorage
- עובד גם ללא אינטרנט (Service Worker)
- אפשרות לשיתוף הרשימה
- עיצוב RTL עברי יפה
